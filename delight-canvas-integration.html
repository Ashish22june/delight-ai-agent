CU Ava 2.0 - Delight Messenger Integration

What This Does: Integrates Delight AI messenger into Canvas for students and guests.

Authentication Paths:

  • Authenticated Students: Detects Canvas student ID and session token → Full access to all features
  • Anonymous Guests: No auth data provided → Limited features (public content, FAQs, support only)

For Canvas Team: Provide window.CANVAS_STUDENT_ID and window.DELIGHT_SESSION_TOKEN for authenticated path. If neither is provided, anonymous session is created automatically.

This file auto-detects user type and initializes Delight appropriately. No configuration needed.
